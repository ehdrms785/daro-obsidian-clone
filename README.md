## 소개

**Daro Obsidian Clone**은 마크다운 파일 기반으로 노트를 작성하고,  
노트 간의 연결(링크), 그래프 뷰, 폴더/파일 관리 등 Obsidian의 핵심 기능을  
웹 환경에서 구현하는 오픈소스 클론 프로젝트입니다.

---

## 주요 기술 스택

- **Next.js (App Router, TypeScript)**
- **Tailwind CSS**
- **Zustand (상태 관리)**
- **TanStack Query**
- **@uiw/react-md-editor (마크다운 에디터)**
- **React Flow (그래프 뷰)**
- 기타: ESLint, Prettier, Jest, GitHub Actions 등

---

## 폴더 구조

```
src/
├── app/ # Next.js App Router (페이지/레이아웃)
├── components/ # 재사용 UI 컴포넌트
├── features/ # 도메인별 폴더 (노트, 그래프 등)
│ ├── notes/
│ ├── vault/
│ └── graph/
├── hooks/ # 커스텀 훅
├── store/ # 글로벌 상태 관리
├── services/ # 비즈니스 로직, API, 파일 관리 등
├── types/ # 타입 정의
├── utils/ # 유틸 함수
├── styles/ # Tailwind 및 글로벌 스타일
└── assets/ # 이미지, 아이콘 등 정적 리소스
```

## 주요 기능 (계획)

- 마크다운 기반 노트 작성/편집/삭제
- 노트 간 내부 링크 및 자동 연결
- 그래프 뷰(노트 네트워크 시각화)
- 폴더/파일(금고) 관리
- 빠른 검색 및 태그
- 반응형 UI, 다크 모드

---

## 프로젝트 목표

- Obsidian의 핵심 사용 경험을 웹에서 재현
- 최신 프론트엔드 트렌드와 실무 아키텍처 적용
- 포트폴리오, 오픈소스, 실전 학습용으로 활용
